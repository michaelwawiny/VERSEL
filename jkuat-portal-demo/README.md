# JKUAT Student Portal Demo

Responsive HTML/CSS/JavaScript demonstration portal with dashboard, profile, academics, sample unit registration, illustrative fees, and sample exam results.

**Not an official JKUAT website.** It does not authenticate accounts, connect to university systems, store passwords, submit registrations, or process payments. Do not enter real credentials.

Run locally: `python3 -m http.server 8000` then visit `http://localhost:8000`.
